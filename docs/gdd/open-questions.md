## A. M1 着手前に決めたいこと

### Q-01【A・最重要】「フリ→ストレート」は“読み”か“見てから”か（4.3）
- GDD: `空振り硬直40F ＞ 溜め8F ＋ 着弾30F − 反応の余裕（数F）`。
- 問題: 40 − 38 = **攻撃側の余裕は2F（約33ms）しかない**。人間の視覚反応は12〜15F、さらに相手の動きは
  100ms（6F）補間で表示されるので、RTT 0 でも「空振りを見てから本投げ」は間に合わない
  （概算で到着まで 6+13+8+30 ≈ 57F 必要）。
  つまり現行値では「相手がキャッチを押しそうな瞬間を読んで本投げを重ねる」予測行動でしか成立しない。
- 選択肢:
  - (a) 読み前提で現行値を維持。テストは「空振り確定フレームで本投げ開始」で判定。
  - (b) 見てから確定を保証。硬直を ~60F に延ばす（または溜め・着弾を短縮）。
    ただしキャッチのリスクが大きくなり、ラリーのテンポにも影響。
  - (c) 反応の余裕 R を data の値にし、テストを `硬直 > 溜め + 着弾 + R + 相手表示遅延` とする。R はプレイテストで決める。
- 提案: **(c)**。初期値 R=12F とすると現行の40Fでは不成立になるため、どちらを動かすかはプランナー判断。
- 回答（2026-09-30）: **見てから当てたい**。コートの前半分くらいからなら見てから当てられる程度。ストレートを速くしてもよい。
- 確定: 不変条件は「受け手がコート前半分（中央線から6m以内）、投げ手が標準位置（中央線から7m）＝距離13m以内」で
  **見てから**成立すること。式: `空振り硬直 ≥ 溜め + 着弾(13m) + 反応R + 通信余裕N`（R=13F、N=3F を data で持つ）。
- **数値案（要承認）**: ストレート初速 28→**32m/s**、空振り硬直 40→**48F（受付終了から）**。
  13m で 8+24.4+13+3=48.4F → 成立。14m（標準距離）では50F必要なので**下がればフリに強い**が残る。
  代替: 初速28のまま硬直52F。
  副作用: ラリー上限時の返球は最速で約45m/s（14mで約19F）。跳ね返し受付9Fと合わせて反応可能か M1 のプレイテストで確認。

### Q-02【A】空振り硬直40Fの起点と、ステップ・スキルで抜けられるか（4.3, 5）
- GDD: キャッチは「発生2F＋受付＋完了22F」、失敗時「硬直40F」。「空振りした側の逃げ道はステップかスキルだけ」。
- 問題: (1) 40F は入力から数えるのか、受付終了から数えるのか（差は8F前後で Q-01 に直結）。
  (2) 「逃げ道はステップ」は硬直中にステップできる＝硬直をステップ・スキルでキャンセルできる、と読める。
- 提案: 受付終了から40F。硬直中は移動・キャッチ・跳ね返し・投擲は不可、**ステップとスキルのみ可**。
- 回答（2026-09-30）: 空振り硬直はステップで抜けられる。ステップはコスト重めなので強めでよい。
- 確定: 起点は受付終了。硬直中は**ステップとスキルのみ可**。

### Q-03【A】不変条件の適用範囲：攻撃ステータスと距離（4.3, 6.1, 2.1）
- 問題: INV-01 は「攻撃5・標準距離14m」でのみ成立する。
  - 攻撃3: 球速25.8m/s → 着弾32.6F、溜め込み40.6F ＞ 40F で**反応0でも不成立**。攻撃1なら44F。
  - 距離: 奥行12m×2 なので最大約24m（着弾51F）。受け手が3m下がるだけで44F。
- 論点: 「下がればフリに強い」は“前後の位置取りに意味が出る”（2.1）として意図どおりか。攻撃の低いキャラはフリが弱くてよいか。
- 提案: 不変条件の適用は「標準距離・攻撃4以上」と明記。下がる行動の代償は上カーブ・狙い投げ・backline_lock が担う。
- 回答（2026-09-30）: 攻撃5（中央値）のキャラで成立すればよい。
- 確定: INV-01 の適用条件は「攻撃5・カウント0・距離13m以内」。攻撃の低いキャラがフリに弱いのは許容。

### Q-04【A】ステップの仕様（3.1, 4.1, 5）
- 未定義: 移動距離・所要フレーム・ステップ中の行動可否・硬直。
- 方向判定の基準が不明: 「前後左右」は **(1) ボールの進入方向**、(2) カメラの向き、(3) キャラの向き のどれ基準か。
  斜め入力（W+A 等）はどちらに分類するか。
- 表記の揺れ: 5章の表は「コスト0、失敗時ポイント1消費」。成功時も消費するのか。
- 提案: 基準は (1) ボールの進入方向。入力ベクトルとの角度で 45°を境に前後/左右に分類（境界ちょうどは両方有効）。
  **成功・失敗にかかわらず1ポイント消費**。距離2.5m・12F、無敵なし。
- 回答（2026-09-30）: 一旦 **5m を素早く移動**。方向の基準は中央線（コートの境目）。相手コート側へ中央線に垂直に進むのが「前」、そこを基準に前後左右。
- 確定: 基準はカメラやボールではなく**コート固定**（前＝中央線の法線方向）。
- 実装デフォルト（未回答部分）: 所要12F（等速ではなく出だしが速いイーズアウト）、斜めは45°境界で分類（境界ちょうどは両方有効）、
  成功・失敗にかかわらず1ポイント消費、無敵なし、フェンス・壁の手前で停止。

### Q-05【A】追尾の強さと「通常移動では絶対に避けられない」（4.2）
- GDD: 「角速度上限つきで旋回」かつ「通常移動では絶対に避けられない」。
- 問題: 旋回に上限があると、至近距離で横移動すれば物理的に外れうる（6m/s の横移動に対し、残り1m で必要な旋回は大きい）。
  上限と「絶対」は両立しない。
- 提案: 旋回上限は見た目の弧のために使い、**残り距離が閾値以下（例 3m）では受け手の胸へ吸着**させる。
  当たり判定は受け手側の判定で行うため、ネット的にも問題ない。
- 回答（2026-09-30）: がっつり追尾。密着してかするくらいの近さなら吸い付いてもよい。
  **ただし、それでキャッチや跳ね返しが難しくなるのはダメ**。
- 確定方針:
  - 旋回上限は大きめ（通常移動では外れない強さ）。吸着は「かする距離」（当たり判定半径＋わずか）だけ。
  - 球速は吸着中も変えない（到達タイミングが読めることを守る）。
  - キャッチ・跳ね返しの判定域は体より大きい別の球で持ち、各 tick で**防御判定を被弾判定より先に**行う。
  - 検証: 吸着あり／なしで、同じ入力タイミングのキャッチ・跳ね返し成否が変わらないテストを置く（INV-21）。

### Q-06【A】返球の速さの決め方と倍率の重ね方（2.3, 5, 6.1, 7）
- GDD: 返球は「ストレート相当」「引き継ぐのは速さだけ」「+6%、上限+40%」。
- 不明点:
  - 基準速度は **受けた球の実速度×(1+0.06)** か、**ストレート28m/s×返した側の攻撃補正×ラリー倍率** か。
    前者だと上カーブ（17m/s）を返すと遅いストレートになる。
  - +6% は加算（6回で+36%→7回目で+40%打ち止め）か乗算（1.06^n）か。
  - 攻撃補正・カウント倍率・ラリー倍率・overcharge の重ね方（全て乗算でよいか）。
  - 返球の威力倍率に、返した時点のカウントを使うか。
- 提案: 返球速度 = 28 × 返した側の攻撃補正 × カウント倍率(返した時点) × (1 + 0.06×n)、n は加算で +40% 打ち止め。
  全て乗算。威力も返した時点のカウントで計算。
- 回答（2026-09-30）: **受けた球の速さ×1.06**。ラリー中にいきなり上カーブで遅くする読み合いもよい。6%は**掛け算**。
- 確定: 返球速度 = 受けた球の実速度 × 1.06（跳ね返しのたびに乗算）。攻撃補正・カウント倍率は返球では掛け直さない。
- 補足: 跳ね返しの返球は常にストレート相当なので、「遅くする」は **キャッチ（ラリーはリセット）→上カーブ** か、
  **上カーブから始まったラリーは遅いまま加速する** の形で起きる。
- 残り: Q-14（返球の威力）。上限は Q-26 で**撤廃**。

### Q-07【A】床のボール：拾い方と物理（2.1, 7, 8#1）
- 未定義: ラウンド開始・被弾後・爆発後・回避されて落ちたボールを**どう拾うか**（接触で自動／キー）。
  外れた球（狙い投げ・追尾解除後）の壁・床での挙動（跳ねる・転がる・止まる）。
- 拾ったとき FPS へ切り替えるか（所持=FPS の原則どおりなら切り替える）。
- 提案: 接触で自動取得（取得モーション10F）→ FPS へ。ボールは重力・反発・摩擦の簡易物理を sim で決定論的に計算。
- 回答（2026-09-30）: 一定距離に近づいたら**自動で拾う**。範囲はキャラより少し大きめでストレスなく。
  床では1〜2回バウンドする程度、壁でもあまり跳ねない。左右カーブ・上カーブが天井に当たらない工夫を。
- 確定: 自動取得（半径はキャラ半径＋余裕、data で管理）→ FPS へ。床の反発は低め（1〜2回で止まる）、壁も低反発。
- 天井対策の方針: 球種の軌道は物理任せにせず、**頂点高さ・横膨らみに上限を持つ誘導曲線**＋追尾補正で生成する。
  上カーブの頂点は `天井高 − 余裕` にクランプ、左右カーブの膨らみはコート幅内にクランプ。
  全球種×全距離×全位置で天井・側壁に当たらないことをテスト（INV-22）。天井高 → Q-27

### Q-15【B】相手の溜め・フリの表示同期（11.3）
- 相手の位置・アニメは state チャネルで100ms 補間表示、投擲はイベントで即時。
  このままだと受け手の画面で**溜めアニメが終わる前にボールが飛び出す**／フリと本投げの見え方の間隔が縮む（フリが強くなる）。
- 提案: 相手の行動アニメ（溜め・フリ・キャッチ等）は補間ではなく行動開始イベント駆動で再生し、
  リリース時刻に合わせてボール再生を開始する。行動開始イベントは「フリか本物か」を含めない（見破り防止）。
- 回答（2026-09-30）: 溜めアニメと同期させる工夫を。
- 確定方針: 相手の移動は100ms補間、**行動アニメ（溜め・フリ・キャッチ等）は行動開始イベント駆動**で再生。
  溜め開始とリリースは同じ遅延で届くので、受け手側で溜めアニメの終わりとボールの発射が揃う。
  発射点はリリースイベントの座標を正とし、補間表示中の相手モデルをそこへ短時間で寄せる。
  行動開始イベントにはフリか本物かを含めない（リリースの有無で初めて分かる）。

## E. 回答から生まれた追加の論点（2026-09-30）

### Q-25【A】ジャストキャッチの定義
- 判定幅: 受付のうちどこを「ジャスト」とするか。
- 「食らう」の中身: 普通のキャッチでスキル効果付きの球を取ったとき、何を受けるか。
- ジャストの付加価値: スキル効果のない通常球でもジャストに意味を持たせるか。
- 提案:
  - ジャスト＝ボール到達の直前2F以内に受付が始まっている（遅めに押すほどジャスト。判定幅は data）。
    iron_grip の+1Fは普通の受付だけ広げる。
  - 普通のキャッチで食らうもの＝その効果の**上乗せ分のダメージ**（overcharge なら 20×0.3＝6）。効果はそこで消える。
    スタン等の状態異常系は、普通のキャッチでも付与する。
  - 通常球のジャスト: 獲得コスト+0.25 と「ジャスト」表示・SE（手触りのご褒美）。
- 回答（2026-09-30）: キャッチの猶予はステータスで上下するので、**ジャストのフレームも同じステータスで上下**させる。中央値なら2F。
- 確定: ジャスト幅はキャッチ受付と同じ段階で変化。初期値（受付→ジャスト）: 4F→1F / 5F→2F / 6F→2F / 7F→2F / 8F→3F
  （≒受付×1/3 の四捨五入、中央値5で2F）。iron_grip の+1Fは受付だけに効き、ジャストは広げない（提案）。
- 確認待ち: 参照ステータスは GDD 5章では**防御**、今回の回答では**敏捷**。data の `catchWindowStat` で切り替え可能にし、決まるまで GDD どおり防御で仮実装。
- 未回答: 「食らう」の中身と通常球のジャストのご褒美 → 上の提案で仮実装。

### Q-26【A】ラリー上限+40%の基準
- 乗算で「受けた球×1.06」なので、上限の基準が要る。
- 提案: **ラリーの最初の1球（投擲時の速度）×1.40** を上限。1.06^5=1.338 → 6回目で上限に張り付く。
  afterburn（+8%）も同じ上限。
- 回答（2026-09-30）: **ラリーは上限なし**。完全な読みでキャッチするのも楽しいし、成功し続ければどちらかが必ず返せなくなるのでそれでよい。
- 確定: 上限撤廃（GDD 5章・8章#4 の「+40%上限」を置き換え）。リセットはキャッチ・爆発・被弾のまま。afterburn は ×1.08。
- 実装上の注意: 高速球が1 tick で判定域をすり抜けないよう、当たり・防御判定は**連続判定（スイープ）**で行う。
