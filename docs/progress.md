  - 試作を同じ URL に再公開（https://claude.ai/artifact/HZRBvv3kNFYov2Bbpdv8KN）。
- 見つかったこと: 取得半径 1.3m だと、スポーン位置（中央線から7m）に立ったままの相手が爆発後の新球（コート中央 6m）をすぐ拾える。
  カウントは凍結中なので不変条件は保たれるが、気になるなら新球の位置か半径を調整する。
- プランナーに確かめてほしいこと（手触り）:
  1. キャッチ・跳ね返しを「球が体に届いた瞬間」に押して間に合うか。まだ早押しが必要か、逆に遅押しでも取れすぎるか。
  2. 球速（35/25/19）が「もう少し速く」に合っているか。
  3. 跳ね返しで A/D/S を押しながら返すと球種が変わるか（トーストに球種名が出る）。ラリー中の上カーブ返しで緩急がつくか。
  4. ストレートを前後ステップで避けようとすると当たり、左右なら避けられるか。
  5. 転がった球を拾うのがストレスなくなったか。
