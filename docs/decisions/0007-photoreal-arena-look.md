# 0007 試合画面の画作り（シネマティック・コンポジット、CSG の仮モデル、手続き的なビル群）

ハーネス `.harness/photoreal-arena/`（Sonnet 5.5 の盲検評価）で回した見た目の作業の設計判断。調査は `docs/research/graphics-compositing.md`。

## 背景
- 盲検評価の基準（2026-09-30）は 36 点・主要物が読める 0/3。指摘は「自キャラが箱」「背景が書き割り」「光がフラット」「ポスト不足」「球と相手が小さい」。
- プランナーの依頼: three-bvh-csg で緻密な物、SkyscraperGenerator 系で背景、TSL ポストでシネマティックに（ゲームとして遊べることが前提）。

## 決定
1. **ポスト**（`src/render/postPipeline.ts`、数値は `data/render.json` の `post`）
   - HDR 段: GTAO（高画質のみ、**法線は深度から復元して MRT を使わない**＝ADR 0005 の半透明の問題を避ける）→ ブルーム（ハレーションで暖色に寄せる）＋レンズフレア（LensflareNode＋ぼかし）→ 画面端だけのぼけと色収差（自作。中心＝照準とコアは触らない）。
   - トーンマップは `RenderPipeline.outputColorTransform = false` にして自分で `renderOutput()` を呼び、その後の**表示色**で SMAA → CDL・S 字・スプリットトーン・ビネット・ライトリーク・グレイン。
   - ChromaticAberrationNode・FilmNode は使わない（中心もずれる／明暗で強さを変えられない）。AnamorphicNode は r186 に無い。
   - 重い物は `quality.json` の `lensFlare`・`edgeBlur`・`filmFx`・`ao` で中・低画質から外す。
2. **CSG**（`src/render/csgParts.ts`、three-bvh-csg 0.0.18）: 選手の仮モデル（面取り・溝・通気口・背中のコアの穴）、支柱、照明トラスと投光器の筐体、LED 帯看板の筐体を**起動時に一度だけ**組む。
   選手は 4 マテリアル（クリアコートの塗装・金属・布のスーツ・発光ライン）。当たり判定は balance.json のまま（見た目だけ）。
3. **遠景**（`src/render/skyline.ts`）: three 公式の `SkyscraperGenerator`（r186 同梱）のジオメトリを使い、**マテリアルは自前の軽い夜用**（光の計算なし・窓は roomCenter のハッシュで点灯）。
   公式マテリアルは部屋をレイマーチしノイズも多く、ソフトウェア描画で 1 フレーム数十秒かかった。窓・看板にチーム色（シアン・マゼンタ）を使わない（選手とコアの色を背景から分ける）。
4. **読みやすさの追加表示**: 相手とコアの足元の輪、相手の頭上のチーム色の光だまり、転がっているコアの上の光の柱（カメラ近くでは消える）、
   画面上で一定の大きさのしるし（コアの光の輪・相手の頭上の下向き三角）。球・キャラの大きさ（balance.json）は変えない。
5. **自分の選手は不透明**（以前は箱で不透明度 0.35）。人型は箱より細く前が見えるため。

## 代替案
- pmndrs/postprocessing・three-gpu-pathtracer: WebGPURenderer 非対応。
- MRT で法線を出す GTAO: 半透明（フェンス）で法線が上書きされる（ADR 0005 と同じ問題）。
- SkyscraperGenerator の標準マテリアル: 重すぎる（上記）。
- 球を大きくする（評価者の直し方）: balance.json の範囲外。

## 不変条件への影響
- コアの可読性: 光らせない物は HDR 1 未満を維持（スキーマで上限）。コアの顔 3.0 より明るい物は無い（投光器のレンズ 2.2・相手の発光ライン 2.4 は面積が小さい）。
  持った球の heldDim は変えていない。持っている間は光の輪・柱を出さない。
- カメラ: 変更なし。操作・判定: 変更なし（src/sim は触っていない）。
- **プレイテストで確かめてほしい**: 不透明な自分の選手で前が見えるか、追加表示（頭上の印・光の柱）が煩くないか。

## 撤回条件
- 実機（ミドルノート PC・Xiaomi 11T 中画質）で予算を超えるとき: 画質段階で外す範囲を広げる（ao・edgeBlur・lensFlare、ビル数は decorMul）。
- プランナーが追加表示や不透明な自キャラを不可としたとき: `data/render.json` の markers・beacon を 0 に、自キャラの不透明度を戻す。
