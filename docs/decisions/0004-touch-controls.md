# 0004 スマホ（横持ち）のタッチ操作

## 背景
プランナー要望: スマホで横持ちで遊べるようにする。左に仮想スティック、右に各ボタン。ボールの所持・非所持で UI を変える。
投げるときはスティックの方向でキーボードと同じく球種を投げ分ける。スキルを追加したらスキルボタンも増やす。
ボタン・スティックの大きさと位置は設定で自由に変えられる。GDD は PC 操作（3.1, 14 章）しか定めていない。

## 決定
- 入力は `src/input/touchControls.ts`（DOM・ポインター）、配置データと計算は `src/input/touchLayout.ts`（DOM 非依存・テストあり）、
  配置の調整画面は `src/ui/touchLayoutEditor.ts`。sim は変更しない（`PlayerInput` にキーボードと同じ形で合流させる）。
- スティックの値は「右・前が +」の生の方向として `keyRight` / `keyForward` にキー入力と足して渡す。
  移動はキーボードと同じくカメラ基準、球種は sim の `throwTypeFromInput` がキーボードと同じしきい値で決める（スティックを倒しきれば同じ判定）。
- ボタンの位置関係はマウスにそろえる: 左クリック＝「投げる」（所持）／「跳ね返し」（非所持）を同じ場所、
  右クリック＝「狙い」（所持）／「キャッチ」（非所持）を同じ場所。ステップ・フリ・一時停止は別。
- **狙い投げの「右押しっぱなし」は、タッチでは押すたびに ON/OFF の切り替え**にする（押したまま別の指で投げるのは親指2本では難しいため）。
  ボールを手放すと OFF。
- 所持中は、いま投げたら出る球種を「投げる」ボタンとスティックの周り（前＝ストレート、左右＝カーブ、後ろ＝上カーブ）に示す。
- 視点は右側の空いた所のドラッグ。ボタンを押したまま指を 10px 以上滑らせても視点が動く。感度は「度 / px」で設定。
- 配置は部品ごとに中心（画面幅・高さの割合）と直径（短辺の割合）で持ち、`localStorage` の `cc.touchLayout` に保存。
  調整画面は所持時・非所持時のタブで両方の配置を決める。ドラッグで移動、スライダーまたはピンチで大きさ。不透明度・視点感度・スティック追従も。
- スキルは sim 未実装のため、スロット（スキル1・スキル2・球召喚）だけ用意。`TouchControls.setSkills()` で表示名を渡したスロットだけボタンが出る。
  押下は `takeEdges()` の `skill1/skill2/summon` に来る（`PlayerInput` にスキルの項目ができたら main で渡す）。
- タッチ端末の判定は `(pointer: coarse)`。PC でも `?touch=1` で出せる。開始時に全画面・横向き固定を試みる（できない環境では何もしない）。縦持ちでは「横向きに」と表示。

## 代替案
- 狙いを押しっぱなしにする（キーボードと同じ）: 親指で狙い＋投げを同時に押す必要があり、スティックも使うと3点同時になるので不採用。
- 球種を専用ボタン（4つ）で選ぶ: 「移動キーで球種」というキーボードと同じ読み合い（回避方向の相性）が崩れるので不採用。
- 位置を px で保存: 機種で崩れるので割合で保存。

## 不変条件への影響
- sim・判定に変更なし。球種はキーボードと同じ関数・しきい値で決まる。
- カメラ: 視点ドラッグは yaw/pitch を直接回すだけ（`CameraRig.turn`）。TPS/FPS 切替の仕組みは変えない。
- 狙いのトグル化は入力の与え方だけの違い（sim が見るのは `secondaryHeld`）。

## 撤回条件
- プレイテストで「狙いのトグル」が誤操作を生む場合は押しっぱなし式を設定で選べるようにする。
- スティックの無反応域・しきい値で意図しない球種が出る場合は、タッチ用のしきい値を別に持つ（その場合は `data/` に置く提案を出す）。
