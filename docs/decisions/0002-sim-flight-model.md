# 0002 sim: ボールの飛翔モデル（誘導曲線＋目標点追尾）

- 状態: 採用
- 日付: 2026-09-30
- 関連: GDD 4.1, 4.2 / invariants INV-02, 03, 04, 11, 21, 22 / open-questions Q-05, Q-07, Q-29

## 背景
GDD 4.2 の推奨は「毎フレーム相手の胸へ角速度上限つきで旋回」。しかしこれでは
- 至近距離で横に動けば外れうる（「通常移動では絶対に避けられない」と両立しない。Q-05）
- 旋回の結果として到達時刻が揺れ、キャッチ・跳ね返しのタイミングが読みにくくなる（INV-21）
- 左右カーブ・上カーブが天井・側壁にぶつかりうる（INV-22）

## 決定
ボールの位置を「弦＋膨らみ」の誘導曲線で表し、弧長で一定速度に進める。
`p(u) = S + (T−S)·u + 左向き·横膨らみ·sin(πu) + 上向き·頂点·sin(πu)`、u は 0→1。
- **追尾中は T（受け手の胸）を毎 tick 更新**。u=1 で必ず胸に届く＝通常移動では避けられない（がっつり追尾、かする距離の吸着を含む）。
- **速さは弧長で一定**。受け手が動いても到達 tick はほぼ変わらない（テストで ±1〜2 tick）。
- **頂点と横膨らみは天井・側壁の手前にクランプ**（`court.trajectoryMarginM`）。
- **有効方向のステップで追尾解除＝T を固定**し、その球は受け手に当たらない（Q-29 の仮実装）。
- 狙い投げは重力なしの直進（linear）。外れた球・落ちた球は低反発の簡易物理（loose）。跳ね返り速度に上限を持たせ、1〜2回で落ち着く。
- 高速球のすり抜け防止: 追尾球は u=1 到達で判定、直進球は線分と体（縦カプセル）の距離で判定。

## 代替案
- GDD 推奨の角速度上限つき旋回: 上記の理由で不採用。見た目の弧は誘導曲線の膨らみで表現できる。
- 物理ベース（力・速度の積分）: 天井・到達時刻の保証が難しい。

## 不変条件への影響
INV-02・21・22 を構造的に保証し、テストで確認（tests/sim/invariants）。

## 撤回条件
プレイテストで「曲がり方が不自然」「急に吸い付いて見える」となった場合、見た目（描画上の補間）で先に調整し、sim の判定は変えない。
