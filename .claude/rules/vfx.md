# VFX 規則（GDD 13章）

## 実装方針
- 看板エフェクト（プラズマ・フェンス、コアの液晶の顔、軌跡、爆発のコア）は TSL の自作シェーダー。
- 汎用パーティクル（火花・破片・煙）はライブラリ可。採用ライブラリは M0 で ADR に残す。
- フェンスのヒット波紋は最大4つを uniform で渡す（配列長固定）。

## メモリと上限
- パーティクル・リボン・デカールは全てプール。**試合中に `new` しない。**
- 1エフェクトの上限をプリセットに持つ（例: 爆発 2,000粒子・1.2秒）。上限超過は古いものから回収。
- 軌跡リボンは頂点バッファを再利用する。

## データ
- プリセットは `data/vfx/<id>.json`。スキル・イベントからは ID で参照し、コードに色や粒子数を直書きしない。
- 全スキルに VFX / SFX / アイコンの ID が揃っていること（キャラ追加の完了条件）。

## 体験上の約束
- コアの顔は残り時間の UI。段階の閾値は data から読む（スマイル→焦り→激怒→点滅→亀裂→破裂）。
- ファントムの幻影は本物と**同じ見た目**。崩れる演出は消滅時のみ。
- キャッチ・跳ね返しの成功演出は最優先で気持ちよく。ただし sim の時間は止めない（Q-11 回答まで）。
- VFX はコアの可読性を下げない。コアより明るい発光を長時間出さない。
- 画面揺れは設定の強度を必ず掛ける。
